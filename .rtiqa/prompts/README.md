# RTIQA Prompts

This directory contains reusable AI prompts and prompt templates for RTIQA engineering tasks.

## Purpose

`prompts/` provides RTIQA-specific prompt patterns that help AI agents generate code, documentation, reviews, and architectural proposals.

## Initial content

- `README.md` — directory overview.
- `code-review.md` — prompt template for AI-assisted code review.
- `documentation.md` — prompt template for generating RTIQA documentation.
- `architecture.md` — prompt template for architecture design and decision support.

## How to use

- AI agents use these prompts as the default instruction templates.
- Contributors reference prompts to keep AI outputs aligned with RTIQA standards.
- Maintainers update prompt templates as RTIQA engineering practices mature.
