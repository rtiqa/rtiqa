# RTIQA AI Engineering

This directory defines how RTIQA uses AI to support development, review, and engineering governance.

## Purpose

`ai/` captures AI-first engineering workflows, evaluation criteria, and responsible usage patterns.

## Initial content

- `README.md` — directory overview.
- `workflow.md` — AI-assisted workflow patterns for RTIQA.
- `evaluation.md` — criteria for evaluating AI outputs.
- `agent-guidelines.md` — guidelines for AI agents operating on RTIQA.

## How to use

- AI agents should consult `ai/workflow.md` before performing engineering tasks.
- Contributors should use `ai/evaluation.md` to validate AI-generated artifacts.
- Maintainers should keep agent guidelines aligned with project rules and governance.
