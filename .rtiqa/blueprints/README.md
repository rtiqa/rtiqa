# RTIQA Blueprints

This directory stores reusable blueprints for RTIQA architecture, feature modules, and integration patterns.

## Purpose

`blueprints/` captures high-level blueprints that define how RTIQA components should be structured and integrated.

## Initial content

- `README.md` — directory overview.
- `module-blueprint.md` — a template for RTIQA feature module design.
- `integration-blueprint.md` — integration patterns for Frappe, ERPNext, and AI services.
- `data-blueprint.md` — data model and storage pattern guidance.

## How to use

- Architecture owners use blueprints to define new RTIQA modules.
- Contributors use blueprints to align new features with the RTIQA design model.
- AI agents reference blueprints during code generation and architectural planning.
