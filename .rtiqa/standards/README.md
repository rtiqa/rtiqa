# RTIQA Engineering Standards

This directory defines the engineering standards that RTIQA uses for long-term development quality.

## Purpose

`standards/` captures project-specific conventions, style guides, verification checklists, and quality gates for RTIQA.

## Initial content

- `README.md` — overview of the standards directory.
- `coding.md` — coding conventions for Python, JavaScript, and Frappe customizations.
- `documentation.md` — documentation quality and formatting expectations.
- `review.md` — review checklist for human and AI contributions.

## How to use

- Contributors should reference `.rtiqa/standards/coding.md` before writing code.
- Reviewers should use `.rtiqa/standards/review.md` during PR review.
- AI agents should follow `.rtiqa/standards/documentation.md` when generating documentation.
