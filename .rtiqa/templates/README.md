# RTIQA Templates

This directory stores RTIQA-specific templates for documents, issues, and architecture artifacts.

## Purpose

`templates/` provides standardized skeletons that contributors and AI agents use to create consistent project artifacts.

## Initial content

- `README.md` — directory overview.
- `doc-template.md` — documentation page template.
- `issue-template.md` — issue description template for internal use.
- `architecture-template.md` — architecture artifact template.

## How to use

- Use templates when creating new docs, issues, or architecture proposals.
- AI agents should populate templates to ensure consistent output.
- Maintainers may extend templates as new project patterns emerge.
