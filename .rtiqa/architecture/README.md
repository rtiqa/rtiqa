# RTIQA Architecture

This directory holds the core architecture models and system design references for RTIQA.

## Purpose

`architecture/` captures architecture diagrams, system patterns, and integration models that define how RTIQA is built.

## Initial content

- `README.md` — directory overview.
- `system-overview.md` — high-level RTIQA system architecture.
- `data-flow.md` — data flow design and integration points.
- `infra-overview.md` — infrastructure patterns for Frappe deployment and AI services.

## How to use

- Architecture owners document major system design decisions here.
- Contributors reference these models when aligning new work to the RTIQA architecture.
- AI agents use these documents during design and generation tasks.
