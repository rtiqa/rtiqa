# RTIQA Decisions

This directory stores architecture decision records (ADRs) and rationale for RTIQA.

## Purpose

`decisions/` captures the why behind major engineering choices, including architecture, tooling, and governance decisions.

## Initial content

- `README.md` — directory overview.
- `0001-record-format.md` — decision record format and metadata.
- `0002-decision-process.md` — how RTIQA records and approves decisions.

## How to use

- Document major decisions in this directory.
- Reference decision records when reviewing project history.
- Update or supersede records rather than deleting them.
