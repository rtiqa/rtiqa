# RTIQA Rules

This directory defines the engineering rules and guardrails that shape safe and consistent RTIQA development.

## Purpose

`rules/` captures constraints, validation rules, and project guardrails for RTIQA engineering.

## Initial content

- `README.md` — directory overview.
- `security-rules.md` — engineering security rules and threat model guidance.
- `ai-usage.md` — rules for responsible AI-assisted development.
- `commit-rules.md` — repository commit and branch guardrails.

## How to use

- Contributors review rules before starting work.
- AI agents use rules to validate generated output.
- Maintainers update rules as the RTIQA project governance and tooling evolve.
