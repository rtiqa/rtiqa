# RTIQA Generators

This directory contains generator definitions and scaffolding for engineering assets.

## Purpose

`generators/` defines reusable generation workflows for project artifacts, such as docs, module scaffolds, and configuration files.

## Initial content

- `README.md` — directory overview.
- `generator-spec.md` — RTIQA generator specification.
- `generator-architecture.md` — generator framework architecture.
- `generator-workflow.md` — generator execution workflow.
- `generator-registry.md` — registry metadata and discovery rules.
- `project-generator.md` — project scaffolding generator.
- `module-generator.md` — module scaffold generator.
- `api-generator.md` — API contract generator.
- `database-generator.md` — schema and migration generator.
- `documentation-generator.md` — docs artifact generator.
- `ui-generator.md` — UI artifact generator.
- `test-generator.md` — test artifact generator.
- `deployment-generator.md` — deployment artifact generator.

## How to use

- Contributors use these generator definitions to bootstrap new engineering assets.
- AI agents use the generator recipes as authoritative creation patterns.
- Maintainers add new generator definitions as RTIQA evolves.
