# Project Roadmap

This roadmap describes the planned phases and priorities for RTIQA.

## Purpose

The roadmap provides a shared direction for contributors and maintainers while remaining flexible to community feedback.

## Phase 1 — Foundation (complete)

- Establish project vision, principles, and architecture
- Create governance, community, and security policies
- Build documentation framework and contribution standards
- Prepare initial repository structure and infrastructure references

## Phase 2 — Developer Experience

- Define local development and container workflows
- Add CI/CD pipelines for linting, testing, and docs
- Publish reproducible environment setup
- Add dependency management and release automation

## Phase 3 — Core Platform Wiring

- Integrate Frappe, ERPNext, and ERPNext Education
- Create the RTIQA app scaffolding
- Implement tenant, user, and school management foundations
- Add authentication and permission models

## Phase 4 — Learning Experience

- Build course, lesson, assignment, and assessment modules
- Add dashboards and reporting capabilities
- Support educator and learner workflows
- Implement mobile and offline sync requirements

## Phase 5 — AI Platform

- Add AI assistant and tutoring workflows
- Implement search, recommendations, and RAG capabilities
- Integrate OpenAI, Gemini, and vector search support
- Add AI governance, validation, and ethical controls

## Phase 6 — Production and Scale

- Harden deployment, monitoring, backup, and security
- Add performance testing and scalability validation
- Build production-ready release artifacts
- Establish support and maintenance processes

## Phase 7 — Public Release

- Conduct beta testing and community previews
- Finalize documentation and onboarding materials
- Publish the first public release
- Grow the open-source community around RTIQA

## How to use this roadmap

- Issues should reference the phase they support.
- Contributions should align with roadmap priorities.
- Significant changes should be proposed and reviewed via issues.

## Feedback and updates

The roadmap is a living document and should be updated as the project evolves.
If you have roadmap suggestions, please open an issue.
