# Contributing Guide

Version: 1.0

Status: Approved

---

# Purpose

This document defines the official contribution guidelines for the Rtiqa platform.

Every contributor, developer, and AI coding agent must follow these rules.

---

# Contribution Principles

- Quality First
- Documentation First
- Security First
- AI First
- Review Before Merge

---

# Branch Strategy

Main Branch

- main

Development Branch

- develop

Feature Branches

- feature/<feature-name>

Hotfix Branches

- hotfix/<issue-name>

---

# Commit Rules

Every commit must

- Be atomic
- Have a clear message
- Pass testing
- Follow project standards

Example

docs: update API documentation

feat: add student attendance module

fix: resolve login issue

---

# Pull Request Rules

Every Pull Request must include

- Description
- Purpose
- Related Issue
- Testing Results

---

# Code Standards

Python

- Black
- Ruff

JavaScript

- ESLint
- Prettier

Documentation

- Markdown
- English
- Version Controlled

---

# Review Process

Every Pull Request requires

- Code Review
- Documentation Review
- Security Review

---

# AI Development Rules

AI-generated code must

- Follow project architecture
- Pass testing
- Include documentation
- Avoid modifying framework core files

---

# Documentation

Every new feature must update

- Architecture
- API
- Database
- User Documentation

---

# Project Values

- Maintainability
- Scalability
- Security
- Performance
- Simplicity
